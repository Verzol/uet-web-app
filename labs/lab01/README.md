# Lab 01 – Tuần 1: Kiến trúc ứng dụng web

Nguồn: lịch học trên https://itest.com.vn/lects/int3306.htm.

Tuần 1 không có đề lab trên trang môn học. Syllabus ghi phần thực hành là "khảo sát w3techs, đọc chuẩn RFC". Tài liệu đọc thêm:

- [w3techs](http://w3techs.com/): thống kê công nghệ web (web server, ngôn ngữ phía server, CMS).
- [RFC 9110](https://datatracker.ietf.org/doc/html/rfc9110) (HTTP Semantics), [RFC 9112](https://datatracker.ietf.org/doc/html/rfc9112) (HTTP/1.1), [RFC 9113](https://datatracker.ietf.org/doc/html/rfc9113) (HTTP/2), [RFC 9114](https://datatracker.ietf.org/doc/html/rfc9114) (HTTP/3).
- Web server: [Nginx](http://nginx.org/), [Apache](https://httpd.apache.org/), [IIS](http://www.iis.net/).
- [Percent-encoding](http://en.wikipedia.org/wiki/Percent-encoding), [URL shortening](https://en.wikipedia.org/wiki/URL_shortening).
