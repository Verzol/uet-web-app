### 2. Môn học tiên quyết

- Lập trình thủ tục
- Lập trình hướng đối tượng
- Nhập môn cơ sở dữ liệu
- Thực hành cơ sở dữ liệu
- Nhập môn mạng máy tính

---

### 3. Mục tiêu môn học

Sau khi hoàn thành môn học, sinh viên có khả năng:

1. Nắm vững một cách hệ thống các khái niệm cốt lõi trong phát triển ứng dụng web.
2. Sử dụng thành thạo các công cụ và kỹ thuật hiện đại để xây dựng ứng dụng web.
3. Phát triển và triển khai (deploy) được ứng dụng web ở mức sẵn sàng cho môi trường thực tế.
4. Nhanh chóng tiếp cận và áp dụng các công nghệ, framework web mới.
5. Tự xây dựng được framework phục vụ phát triển web.

---

### 4. Chuẩn đầu ra (Learning Outcomes)

| Mã | Chuẩn đầu ra |
|---|---|
| LO1 | Giải thích kiến trúc ứng dụng web, giao thức HTTP và vòng đời request/response. |
| LO2 | Xây dựng giao diện web bằng HTML, CSS, responsive design (Flexbox, Grid, fluid typography). |
| LO3 | Lập trình phía client bằng JavaScript: DOM, sự kiện, AJAX, JSON, lập trình bất đồng bộ, PWA. |
| LO4 | Lập trình phía server: định tuyến, xử lý cơ sở dữ liệu, URL rewriting, quản lý trạng thái. |
| LO5 | Áp dụng các biện pháp bảo mật: xác thực, phiên làm việc, kiểm soát truy cập, kiểm thử đầu vào. |
| LO6 | Sử dụng framework front-end và back-end; viết kiểm thử web tự động. |
| LO7 | Làm việc nhóm để phân tích, thiết kế, phát triển và trình bày một dự án web hoàn chỉnh. |

### 6. Kế hoạch giảng dạy chi tiết

| Tuần | Nội dung lý thuyết | Thực hành / Lab |
|---|---|---|
| 1 | Kiến trúc ứng dụng web; giao thức HTTP | Khảo sát w3techs; đọc chuẩn RFC |
| 2 | HTML; quản trị web | Quản lý ứng dụng web |
| 3 | CSS; typography | Bố cục: thư, trang web, menu, tab |
| 4 | CSS (tiếp); Responsive Web Design; Flexbox; Grid | Flexbox, Grid, fluid typography |
| 5 | JavaScript; DOM; AJAX; JSON | Form, bảng, sắp xếp, xử lý JSON |
| 6 | JavaScript bất đồng bộ; PWA | Animation, web worker, jQuery |
| 7 | Công nghệ web động; công bố đồ án môn học | Lọc dữ liệu; triển khai PWA |
| 8 | URL rewriting; thao tác cơ sở dữ liệu | **Thi giữa kỳ** (trắc nghiệm trên máy) |
| 9 | Quản lý trạng thái; bảo mật | Định tuyến, xác thực, phiên làm việc |
| 10 | Framework; kiểm thử web | Kiểm soát truy cập; kiểm thử validation |
| 11–15 | Seminar / hướng dẫn đồ án; đi sâu framework | Phát triển đồ án nhóm |
| 16 | Bảo vệ đồ án; tổng kết | Trình bày sản phẩm |

**Framework được giới thiệu**

- Front-end: React, Next.js, Angular, Vue, Nuxt
- Back-end: Laravel, Django, FastAPI, Spring Boot, ASP.NET Core, Express, Fastify
- Kiểm thử: Playwright, Cypress
